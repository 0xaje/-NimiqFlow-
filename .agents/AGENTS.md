# Workspace Guidelines & Rules for KorriPay

## Core Development Rules
1. **Real Product Code Only (No Mocks / No Simulators)**:
   - Always implement actual production-ready integrations and real logic.
   - Do NOT use dummy mock data, simulated responses, or fake stubs. If a prompt mentions mocks or simulators, strip them out and replace them with real implementations.

2. **Frequent Git Commits**:
   - Always commit working code increments to git regularly after completing logical tasks or features.
